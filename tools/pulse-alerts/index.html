Pulse alerts

Copy this folder. Run your own Telegram pings on big PulseX / HEX swaps. No account with us.

  1. Download the pulse-hex-kit → open tools/pulse-alerts/
  2. Windows: double-click SETUP.cmd
  3. Put BotFather token + chat id in config.env
  4. Double-click START.cmd
python alert.py --dry-run --once

That line tests the public feed with zero Telegram credentials.
